## Objectif

Avoir employé une fois une forge, GitHub, de bout en bout : un dépôt distant,
`push`, `pull`, `clone`, un conflit et une pull request. La séance travaille
sur le dépôt git du projet 4, et ne demande pas d'écrire de code nouveau.

## Contenu prévu

```{list-table}
:header-rows: 1

* - Partie
  - Ce qu'on y fait
  - Durée
* - La forge
  - un compte, un dépôt distant, `remote`, `clone`, `push`, `pull` ; une
    branche de fonctionnalité et une pull request
  - 15 min
* - Publier son dépôt
  - créer un dépôt vide sur GitHub, `git remote add origin`, `git push`
    avec la clé SSH du cours 5, voir l'historique sur le site
  - 20 min
* - Deux copies du même dépôt
  - `git clone` dans un autre dossier, un commit dans ce clone, `push`,
    puis `pull` dans le premier dossier
  - 20 min
* - Un conflit
  - la même ligne du README modifiée sur le site et en local ; `pull`,
    résoudre le conflit, `push`
  - 20 min
* - Une pull request
  - une branche qui améliore le README, poussée ; la pull request ouverte
    puis fusionnée sur le site ; `pull` en local
  - 20 min
```

Les élèves qui n'ont pas terminé le projet 4 partent d'un dépôt de référence,
à copier et publier à la place du leur.

## Avant la séance

Déclarer sur GitHub la clé SSH créée au cours 5. Garder le dépôt git du
projet 4 sur le poste, ou le copier sur une clé USB.
