Ces pages décrivent la configuration des logiciels du module sur les postes
de la salle, dans l'ordre où on les configure :

- [Anaconda](anaconda.md), la distribution Python et conda
- [Git et Git Bash](git.md), le terminal du module à partir du cours 1, et
  git à partir du cours 2
- [VS Code](vscode.md), en quatre pages : [généralités](vscode.md),
  [Python et environnement conda](vscode_python.md),
  [notebooks](vscode_notebooks.md), et les [fichiers de
  réglages](vscode_reglages.md) prêts à recopier
- [Spyder](spyder.md), employé dans d'autres cours
- [JupyterLab hors Anaconda](jupyterlab.md), lancé seul dans un terminal

La comparaison des trois outils qui exécutent du Python est dans [Choisir
entre JupyterLab, Spyder et VS Code](../notions/outils.md), parmi les
notions.

Les vérifications à faire avant les séances sont dans
[Premiers tests du poste](../../avant/poste.md) ; l'installation chez
soi, dans [Configuration d'un ordinateur personnel](../poste_personnel/index.md) ;
les problèmes rencontrés en séance, dans la [FAQ](../faq.md) ; ce que sont
un terminal et une variable d'environnement, dans [Notions](../notions/index.md).
