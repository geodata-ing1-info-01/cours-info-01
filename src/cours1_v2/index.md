Trois parties, qui alternent une explication courte et des TD sur machine.


## Ce qui change par rapport à 2026

La séance de 2026 comptait 123 diapositives et dix TD pour deux heures ; la
partie sur les bibliothèques et les environnements n'a pas été jouée. La
version 2 suit le syllabus v2 du module, `syllabus/02_syllabus_v2.md` dans
le dépôt :

- l'éditeur de code VS Code et sa configuration passent au cours 2, faits
  en classe entière ;
- le terminal, vu au cours 2 en 2026 sans TD, arrive au cours 1, avec un TD
  en Git Bash, le terminal de tout le module ;
- le premier programme s'écrit dans Notepad++ et se lance dans Git Bash ;
- le stockage (disque du poste, dossier partagé) devient une notion de la
  partie 1 ;
- le binaire et le texte passent au cours 3 ; Markdown au cours 2, sauf la
  syntaxe minimale d'une cellule de notebook ;
- les environnements passent au cours 3, par la pratique ;
- l'indentation et le TD des programmes fautifs passent au cours 2 v2, où
  l'éditeur de code les souligne.

Les diapositives sont dans le dépôt, `src/cours1_v2/diapo/cours1_v2.pdf`.
