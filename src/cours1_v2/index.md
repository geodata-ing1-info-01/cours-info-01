La séance rappelle le fonctionnement d'un ordinateur, puis fait découvrir la
ligne de commande et lancer un premier programme Python. Chaque partie se
termine par un TD sur machine.

```{list-table}
:header-rows: 1

* - Partie
  - Contenu
  - TD
* - [Matériel, logiciels, fichiers et stockage](notebook/01_logiciels_stockage.md)
  - les composants d'un ordinateur ; ce que fait un logiciel ; les fichiers,
    leur extension et leur chemin ; les emplacements où ils sont enregistrés,
    sur l'ordinateur ou sur le réseau
  - 1a
* - [Le terminal](notebook/02_terminal.md)
  - la ligne de commande dans Git Bash : structure d'une commande, commandes
    de base, chemins
  - 1b
* - [Premier programme](notebook/03_premier_programme.md)
  - lancer un programme Python dans le terminal ; comment le terminal trouve
    le programme d'une commande ; langage compilé et langage interprété
  - 1c
* - [Un notebook et la syntaxe de Markdown](notebook/04_notebook.md)
  - un document qui réunit texte, code et résultats ; une cellule de texte
    en Markdown ; le lancement de JupyterLab
  - 1d
```
