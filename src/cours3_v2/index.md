---
title: "Séance 3 — Fichiers, chemins et programme en ligne de commande"
---

La séance montre comment un script Python lit et écrit des fichiers, puis
comment l'écrire pour qu'il fonctionne avec d'autres données et sur le poste
d'une autre personne. Elle emploie pour cela deux bibliothèques fournies avec
Python, `pathlib` pour les chemins et `argparse` pour les arguments de la
ligne de commande.

L'exposé est suivi de trois TD, faits dans VS Code :

- TD 3a, dénivelé d'une trace GPS ;
- TD 3b, portabilité d'`altitudes.py` et fusion d'une branche ;
- TD 3c, facultatif, les ordres de grandeur de votre poste.

Les fichiers et la feuille de chaque TD sont dans l'archive de la séance,
`info01-cours3.zip`, avec les diapositives, `diapositives_cours3.pdf`.
