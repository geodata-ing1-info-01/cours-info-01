TD 7a — Compléter un projet GitHub, par des pull requests#

Note

Les fichiers des TD de la séance sont dans l’archive info01-cours7_v1.zip.

Le TD part d’un dépôt GitHub publié par le module, td7a-recette, le même pour tous : il contient le programme recette.py du corrigé du TD 4a, avec son historique. Le TD ajoute de nouvelles fonctions à ce programme. Au départ, le programme calcule les ingrédients d’une recette pour un nombre de personnes et les écrit dans un fichier CSV. À la fin du TD, il écrit aussi, pour chaque recette, une page HTML qui réunit le texte de la recette et le tableau des quantités calculées, puis un sommaire qui relie ces pages, comme un livre de recettes.

Le TD ajoute ainsi deux fonctionnalités au programme : générer la page HTML d’une recette (étapes D1 et D2), puis générer les pages HTML de toutes les recettes et leur sommaire (étapes D3 et D4). Vous développez chacune sur sa propre branche, puis vous l’ajoutez à master par une pull request, fusionnée sur le site de GitHub.

Le guide donne les modifications du programme par blocs. Les lignes en vert, entre deux lignes +++, sont à ajouter : les copier telles quelles, sans les lignes +++. Les lignes en rouge, entre deux lignes ---, sont à supprimer. Les autres lignes ne changent pas et indiquent l’endroit : le nombre qui les précède est le numéro de la ligne dans VS Code, quand les modifications sont faites de haut en bas.

D1 · Générer la page HTML d’une recette#

À faire : sur une branche page : modifier le programme pour qu’il complète le texte de la recette par le tableau des ingrédients (D1.1), puis convertisse ce texte en page HTML en appelant pandoc, avec une feuille de style (D1.2) ; faire un commit à la fin de D1.1 et à la fin de D1.2.

À obtenir : python recette.py crepes -p 6 --page écrit sortie/crepes.md, puis sortie/crepes.html, la page de la figure du début du guide.

Au départ, recette.py écrit les quantités d’une recette dans un fichier CSV. L’étape D1 modifie ce programme pour qu’il écrive aussi la page HTML de la recette, celle de la figure du début du guide. Cette page réunit deux choses : le texte de la recette (le titre, le temps de préparation, les étapes), écrit à la main dans un fichier Markdown, et le tableau des ingrédients, que le programme calcule déjà. Les fichiers Markdown des recettes sont fournis dans le dossier depart/recettes/ du TD, cours7/7a_recette/depart/recettes/, hors du projet.

Les modifications à faire, dans l’ordre :

  1. Copier le texte des recettes du dossier depart/recettes/ du TD dans le dossier recettes/ du projet, un fichier Markdown par recette. Ce texte sert de modèle : sa section ## Ingrédients est vide, et le programme la remplit.

  2. Écrire une fonction, tableau(ingredients), qui reçoit la liste des ingrédients et renvoie leur tableau Markdown, sous forme de texte.

  3. Écrire une fonction, ecrire_markdown(nom, personnes, unites, ingredients). Elle reçoit le nom de la recette ("crepes"), le nombre de personnes et le système d’unités ("SI" ou "US"), qui servent au titre de la section, et la liste des ingrédients. Elle lit le texte de la recette, recettes/<nom>.md, place le tableau sous ## Ingrédients, écrit le résultat dans sortie/<nom>.md, et renvoie le chemin de ce fichier.

  4. Modifier le programme principal pour qu’il écrive ce texte complété, seulement quand la commande porte une nouvelle option, --page : python recette.py crepes -p 6 --page. Sans l’option, le programme fait ce qu’il faisait avant. Une option sans valeur, comme --page, est décrite dans la documentation d’argparse, partie « Introduction aux arguments optionnels ».

  5. Écrire une fonction, ecrire_page(markdown), qui reçoit le chemin du texte complété, le convertit en page HTML avec pandoc, et renvoie le chemin de la page.

  6. Ajouter une feuille de style, style.css, qui fixe la présentation de la page : polices, couleurs, largeur du texte, bordures du tableau. ecrire_page copie ce fichier dans sortie/, à côté de la page, avec la fonction shutil.copy (TD 3f), décrite dans la documentation de shutil.copy.

Les modifications 1 à 4 forment l’étape D1.1, les modifications 5 et 6 l’étape D1.2. Créer d’abord une branche, page, pour y faire les six modifications :

git checkout -b page

Essayer avant de regarder la solution. Pour chaque modification, lire d’abord son explication, puis écrire le code soi-même avant de regarder le bloc qui indique la solution. Les cours précédents présentent tout ce dont ce code a besoin : la liste de tuples des ingrédients et les fonctions (TD 4a), la lecture et l’écriture d’un fichier texte (TD 3c), argparse (TD 3f, et étape B6 du TD 4a), pandoc lancé par subprocess.run et la copie d’un fichier par shutil.copy (TD 3f). D1.1 Ajouter le tableau des ingrédients au texte de la recette#

Les deux nouvelles fonctions lisent le texte d’une recette, y ajoutent le tableau de ses ingrédients, et écrivent le texte complété. Les paragraphes suivants montrent ces données sur l’exemple des crêpes, pour 6 personnes en unités SI.

Le texte de la recette. Le texte de chaque recette est fourni dans le dossier depart/recettes/ du TD, un fichier Markdown par recette. Le texte des crêpes :

# Crêpes

*10 minutes de préparation, 1 heure de repos.*

## Ingrédients

## Préparation

1. Mélanger la farine et le sel dans un saladier.
2. Casser les œufs au centre et mélanger.
3. Verser le lait **peu à peu**, sans cesser de remuer.
4. Ajouter le beurre fondu.
5. Laisser reposer une heure.
6. Cuire dans une poêle chaude, une minute par face.

Sa section ## Ingrédients est vide : la fonction ecrire_markdown y placera le tableau des ingrédients.

La liste des ingrédients et son tableau Markdown. Dans le programme, les ingrédients d’une recette sont une liste de tuples, un tuple par ingrédient : son nom, sa quantité et son unité. lire_ingredients lit cette liste dans le fichier CSV, puis adapter et convertir en recalculent les quantités. L’opérateur + met deux chaînes bout à bout : si nom vaut "Farine", "| " + nom + " |" vaut "| Farine |". Un nombre se convertit d’abord en chaîne avec str : str(375.0) vaut "375.0". def tableau(ingredients):
    """Le tableau Markdown des ingrédients, une ligne par ingrédient."""
    texte = "| Ingrédient | Quantité |\n"
    texte = texte + "|---|---|\n"
    for nom, quantite, unite in ingredients:
        texte = texte + "| " + nom + " | " + str(round(quantite, 1)) + " " + unite + " |\n"
    return texte


def ecrire_markdown(nom, personnes, unites, ingredients):
    """Le texte de recettes/<nom>.md, avec le tableau des ingrédients sous « ## Ingrédients », écrit dans sortie/ ; renvoie son chemin."""
    source = (DONNEES / (nom + ".md")).read_text(encoding="utf-8")
    intitule = "## Ingrédients pour " + str(personnes) + " personnes, en unités " + unites
    remplacement = intitule + "\n\n" + tableau(ingredients)
    complete = source.replace("## Ingrédients", remplacement)
    markdown = SORTIE / (nom + ".md")
    markdown.write_text(complete, encoding="utf-8")
    return markdown

D1.2 Générer la page HTML en appelant pandoc#

La modification 5 produit la page HTML avec pandoc. La modification 6 lui donne ensuite sa présentation, par une feuille de style.

La page HTML, par pandoc. pandoc convertit un fichier Markdown en page HTML, comme au cours 3. L’appel ecrire_page(markdown), où markdown est le chemin sortie/crepes.md que renvoie ecrire_markdown, lance pandoc avec subprocess.run. pandoc écrit la page sortie/crepes.html : le même chemin, avec l’extension .html (with_suffix(".html")). ecrire_page renvoie ce chemin. Pour les crêpes, ecrire_page lance la même commande que celle-ci, tapée dans le terminal depuis le dossier du projet :

pandoc sortie/crepes.md -o sortie/crepes.html --standalone --metadata pagetitle="Crêpes"

ecrire_page construit cette commande pour n’importe quelle recette : elle calcule le chemin de la page et le titre à partir de markdown. Le titre de la page, Crêpes, vient de la première ligne du fichier, # Crêpes. readline lit cette ligne, fin de ligne comprise (TD 3c) ; strip() retire la fin de ligne, puis lstrip("# ") retire le # et l’espace du début.

La feuille de style. Une page HTML décrit son contenu : un titre, des paragraphes, un tableau. Sa présentation est décrite à part, dans une feuille de style CSS, comme au cours 1. La feuille style.css, fournie dans le dossier depart/ du TD, met le texte dans une colonne centrée d’environ 70 caractères, sur un fond crème, souligne les titres de section et aligne à droite les quantités du tableau. Les dix pages et le sommaire partageront cette feuille : une modification de style.css changera la présentation de toutes les pages, sans toucher à leur contenu. L’option --css style.css de pandoc ajoute dans la page un lien vers style.css, à la place de la mise en forme que pandoc y met par défaut. def ecrire_page(markdown):
    """La page HTML d'un fichier Markdown de sortie/, par pandoc ; renvoie son chemin."""
    with open(markdown, encoding="utf-8") as fichier:
        premiere_ligne = fichier.readline()

    titre = titre.lstrip("# ")
    page = markdown.with_suffix(".html")

    return page

def noms_des_recettes():
    """Le nom de chaque recette de recettes/ : ses fichiers .csv, sans l'extension."""
    noms = []
    # Plus court : sorted(DONNEES.glob("*.csv")) ne donne que les fichiers .csv, sans le test
    for chemin in sorted(DONNEES.iterdir()):
        if chemin.suffix == ".csv":
            noms.append(chemin.stem)
    return noms

def ecrire_sommaire(noms):
    """Le sommaire : sortie/index.md, un lien vers la page de chaque recette, puis sa page HTML ; renvoie son chemin."""
    texte = "# Le livre de recettes\n\n"
    for nom in noms:
        with open(DONNEES / (nom + ".md"), encoding="utf-8") as fichier:
            premiere_ligne = fichier.readline()
        titre = premiere_ligne.strip()
        titre = titre.lstrip("# ")
        texte = texte + "- [" + titre + "](" + nom + ".html)\n"
    markdown = SORTIE / "index.md"
    markdown.write_text(texte, encoding="utf-8")
    return ecrire_page(markdown)
