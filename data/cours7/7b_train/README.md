# Reprendre et compléter le projet d'un autre — TD 7b, projet 7, parcours avancé

Le TD part du dépôt `train`, publié sur GitHub par le module : un programme
qui fabrique la vidéo de deux plans du paysage défilant sur un fond. Il le
fait tourner, le lit, puis lui ajoute la fenêtre du train et les ombres des
poteaux, calculées avec numpy, sur deux branches parties du même commit. La
seconde pull request s'arrête sur un conflit, résolu sur le poste.

| Dossier | Ce qu'il contient |
|---|---|
| `travail/` | vide : le dépôt `train` y est cloné à l'étape E0 |

Le guide détaillé, `guide_7b_train.pdf` (aussi en `.html` et en notebook
`guide.ipynb`), détaille chaque étape.

## Les étapes

| | Ce qu'on fait |
|---|---|
| E0 | cloner le dépôt `train`, le pousser vers son compte ; l'environnement `train` ; la vidéo |
| E1 | lire `decor/plans.csv` et la fonction `image` |
| E2 | branches `fenetre` et `poteaux` ; la fenêtre ; la pull request de `fenetre` |
| E3 | les ombres des poteaux avec numpy ; la pull request de `poteaux`, le conflit résolu |
| E4 (bonus) | un troisième plan, une ligne de plus dans `decor/plans.csv` |
