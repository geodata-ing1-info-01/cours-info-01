# Le livre de recettes — TD 7a, projet 7

La suite du programme `recette.py` du TD 3a : toutes les recettes et un
sommaire, la photo de chaque recette, puis la recherche des recettes
faisables avec une liste d'ingrédients, calculée avec numpy. Chaque
fonctionnalité se développe sur une branche du dépôt GitHub du cours 6, et
arrive sur `master` par une pull request. Le guide `guide_7a_recette.pdf`
(aussi en `.html` et en notebook `guide.ipynb`) détaille les étapes.

| Fichier | Ce qu'il contient |
|---|---|
| `depart/recettes/` | vingt recettes de plus (`recette.md`, `ingredients.csv`), à copier dans le dossier `recettes/` du dépôt |
| `depart/modeles/environment.yml` | l'environnement du dépôt : Python et pandoc ; Pillow et numpy s'y ajoutent pendant le TD |
| `travail/` | vide : le clone du dépôt |

Conception : `syllabus/cours/7_projet_effets/contenu_detaille.md`.
