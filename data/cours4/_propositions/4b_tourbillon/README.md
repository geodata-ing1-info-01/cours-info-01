# La Vague en tourbillon — TD 4b, cours 4

Le TD a deux parties. Deux documents les décrivent : la feuille
`td_4b_tourbillon.pdf` donne les étapes en résumé ; le guide `guide_4b_tourbillon.pdf`
(aussi en `.html` et en notebook `guide.ipynb`) les détaille, avec le code à
coller et la vérification de chaque commande.

- Partie A : créer l'environnement `animation`, lancer JupyterLab depuis cet
  environnement et exécuter le notebook `tourbillon.ipynb`, qui fabrique la
  vidéo.
- Partie B : construire le programme `tourbillon.py`, lancé depuis un
  terminal, fonctionnalité par fonctionnalité (une image, une série
  d'images, la vidéo), une branche git par fonctionnalité.

| Fichier | Ce qu'il contient |
|---|---|
| `depart/environment.yml` | la description de l'environnement `animation` : Python, JupyterLab, ImageMagick, ffmpeg |
| `depart/notebook/tourbillon.ipynb` | le notebook qui fabrique la vidéo |
| `depart/vague.jpg` | *La Grande Vague* de Hokusai, 2 000 pixels de large (The Met, CC0) |
| `depart/CREDITS.md` | d'où vient l'image |
| `depart/modeles/` | `README.md` et `pyproject.toml` à compléter, partie B |
| `travail/` | vide : la copie du notebook (partie A) et le dossier du projet `tourbillon/` (partie B) |
