# Une ligne de commande pour la recette — TD 4b, projet 4, parcours standard

Le TD 3a du cours 3, fait au projet 4 par le parcours standard. Le texte du
TD est celui du cours 3 ; seuls son numéro et son dossier changent.

| Fichier | Rôle |
|---|---|
| `depart/recettes/`, `depart/style.css` | les recettes, avec leurs photos |
| `depart/modeles/` | les modèles de README et de `pyproject.toml` |
| `depart/secours/recette.py` | le programme à la fin de l'étape 1, pour qui n'a pas fini |
| `travail/` | vide : le dossier du programme et son dépôt git |

`make_data.py build` recopie ces fichiers depuis le TD 3a du cours 3 (lancer
d'abord `make_data.py build` du cours 3). La feuille et le guide sont écrits
par `reprendre_td3a.py`, à partir de ceux du TD 3a.
