Configuration des postes de la salle

Configuration des postes de la salle#

Ces pages décrivent la configuration des logiciels du module sur les postes de la salle, dans l’ordre où on s’en sert :

  • Anaconda

  • JupyterLab

  • VS Code, en quatre pages : généralités, Python et environnement conda, notebooks, et les fichiers de réglages prêts à recopier

  • Git et Git Bash, pour le cours 2

  • Spyder, employé dans d’autres cours

La comparaison des trois outils qui exécutent du Python est dans Choisir entre JupyterLab, Spyder et VS Code, parmi les notions.

Les vérifications à faire avant les séances sont dans Premiers tests du poste ; l’installation chez soi, dans Configuration d’un ordinateur personnel ; les problèmes rencontrés en séance, dans la FAQ ; ce que sont un terminal et une variable d’environnement, dans Notions.
