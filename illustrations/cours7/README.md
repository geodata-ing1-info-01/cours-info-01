# Images — Cours 7

Les images des schémas du TD 7b (`src/cours7/diapo/schemas.typ`), calculées
par les programmes du TD : les couches de l'image de départ (`train_fond`,
`train_voiles`, `train_plage_jaune`, `train_depart`), la fenêtre et le calque
des poteaux sur un damier (`train_fenetre`, `train_calque_poteaux`), et
l'image avec chaque effet (`train_avec_fenetre`, `train_avec_poteaux`,
`train_final`). Toutes montrent l'image numéro 3.

    cd data/cours7
    python make_data.py illustrations
